# 學習素材累積

給花蓮高商高一學生使用的前端小工具。已完成主介面、新增素材、列表、編輯、照片匯入與單筆 PDF 匯出初版，JSON 備份會在下一輪補上。

## 部署

1. 把整個資料夾推到 GitHub repository。
2. 到 GitHub Pages 設定，選擇部署 root 目錄。
3. 開啟產生的網址即可使用，不需要後端、不需要 build。

## 技術選擇

- Vanilla HTML/CSS/JS：降低維護成本，GitHub Pages 可直接部署。
- localStorage：初版先保存文字素材，符合離線優先與無登入。
- IndexedDB：照片壓縮後存在瀏覽器本機資料庫，避免塞爆 localStorage。
- 瀏覽器列印匯出 PDF：按「匯出 PDF」後產生乾淨列印版，學生選「儲存成 PDF」。這個做法離線可用，中文文字可複製；之後若要自動下載與估算 4MB，可再接 pdfmake。
- 背景圖使用根目錄 `future-full-bright.png`，介面可見；未來 PDF 匯出不會使用背景圖。

## 初版功能

- 主畫面顯示累積筆數與今日提示。
- 新增「課程學習成果 / 多元表現」素材。
- 三件事欄位依類型切換，全部選填。
- 素材列表可篩選、展開、編輯、刪除。
- 課程學習成果的科目由學生自己輸入。
- 可附加照片，照片會壓縮後保存在這台裝置。
- 單筆素材可匯出乾淨 PDF，PDF 不含背景圖與工具標誌。

## 關於流量與 FOMO

學生端暫不顯示全站流量或總筆數。原因是全站統計需要後端或第三方追蹤，會破壞完全靜態、離線優先、無追蹤的原則；也可能讓學生把注意力放在比較，而不是先留下自己的素材。後續若真的需要，可只在老師端用 GitHub Pages 後台流量觀察，不放進學生介面。
